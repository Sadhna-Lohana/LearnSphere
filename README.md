# LearnSphere 📚

**LearnSphere** is a modern and responsive educational website designed to provide users with a clean, engaging, and user-friendly learning experience.

## 🌟 Features

- Clean and modern user interface
- Responsive website design
- Easy navigation
- FAQ section
- Testimonials section
- Interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
LearnSphere/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR-REPOSITORY-LINK
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
